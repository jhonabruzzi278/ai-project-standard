# AI Project Standard

AI Project Standard es una base común para organizar, documentar y gobernar proyectos de software asistidos por inteligencia artificial.

## Relación con Hermes

Hermes utilizará este repositorio como su estándar operativo: consultará sus convenciones, perfiles, políticas, plantillas y habilidades aprobadas al trabajar en otros proyectos.

## Componentes principales

- `standards/`: estándares generales del proyecto.
- `methodologies/`: metodologías de trabajo, incluida AI-DLC.
- `policies/`: límites de autonomía, permisos y aprobaciones.
- `profiles/`: criterios específicos por tecnología.
- `skills/`: registro y organización de habilidades disponibles.
- `templates/`: plantillas reutilizables.
- `schemas/`: esquemas estructurados para proyectos.
- `prompts/`: instrucciones base para Hermes.
- `integrations/`: notas sobre integraciones externas.

## Estado

Este repositorio se encuentra en estado experimental (`v0.1.0`). Su contenido inicial define la estructura y los puntos de extensión; las reglas detalladas se completarán y validarán con proyectos reales.

> Hermes propone. El propietario decide.
