# Requirements

- Distinguish user need, functional behavior, quality constraint and implementation choice.
- Give requirements stable identifiers and measurable acceptance criteria.
- Derive current behavior from code only when evidence supports it.
- Maintain traceability from intent to requirements, stories, design units and tests.
- Surface contradictions, missing decisions and external dependencies before construction.
- Do not promote assumptions to approved requirements without a human gate.
