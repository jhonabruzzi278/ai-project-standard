# Operations

- Identify deployment targets, infrastructure definitions, environments and release mechanisms from evidence.
- Review health checks, logs, metrics, traces, alerts, SLOs, backups, restore tests and incident ownership.
- Treat deployment execution, provisioning and production queries as separately gated operations.
- Propose rollback and verification steps for every material release path.
- Distinguish configuration present in the repository from configuration proven active in production.
- Include cost and capacity risks when evidence makes them relevant.
