# Quality Engineering

- Inventory test frameworks, locations, scripts, fixtures, coverage configuration and CI execution.
- Distinguish tests that exist from tests that were actually executed successfully.
- Map critical behaviors and requirements to test coverage; highlight untested risk, not raw file counts.
- Review determinism, isolation, failure diagnostics and environment assumptions.
- In read-only mode, propose exact safe validation commands but do not execute project scripts.
- Prioritize a minimal confidence ladder: static checks, focused tests, integration tests, build, then broader validation.
