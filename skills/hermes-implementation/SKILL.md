# Implementation

This skill is inactive in read-only analysis.

When an approved construction gate enables it:

- Work only in the authorized project and approved unit.
- Preserve unrelated user changes and existing conventions.
- Keep diffs reviewable and map changes to approved requirements and design.
- Add or update proportionate tests and documentation.
- Do not install dependencies, migrate data, publish, deploy or operate Git remotely without separate authorization.
- Stop on unexpected destructive impact, ambiguous ownership or failed safety checks.
